# Keyboard

Click on the page background first (so no field has focus), then try each key. They need no modifier; Ctrl, Cmd and Alt combinations belong to the browser and are left alone.

| Key | Does |
|---|---|
| `T` | cycle the theme |
| `C` | show or hide the contents panel |
| `F` | go to the Files panel (focus lands on the current document) |
| `R` | raw or rendered |
| `E` | edit in your editor on `file://`; over http it says why it can't |
| `D` | export, in the format chosen in Settings |
| `A` | pause or resume auto-reload |
| `S` | Settings |
| `+` / `-` | larger / smaller text (`=` also works for `+`) |
| `0` | normal text size |
| `W` | cycle the page width |
| `J` / `K` | next / previous heading (this page has several, below) |
| `?` | the list of shortcuts; `?` or Esc closes it |

Open **Settings**: the **Keyboard shortcuts** row is highlighted while they are on, and clicking it turns them off (like Auto-reload). Its gear lists every key: type a new key into a box to change it (a key already in use is refused), press Backspace or Delete in a box to clear that shortcut, or press **Restore the default keys**. Tooltips on the toolbar show each key while they are on.

## The Files tree

Press `F`, or Tab into the Files panel (it takes one Tab stop however many files there are, so another Tab leaves it).

- Up and Down move between rows; Home and End jump to the first and last.
- Right opens a folder; Right again moves into it.
- Left closes an open folder, or moves from a file to its folder.
- Typing letters jumps to the next name that starts with them.
- Enter opens a document. Esc returns to the page.
