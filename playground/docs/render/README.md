# Render showcase

One short page per thing mt-md can draw. Open each, then flip **Raw** (the toggle in the toolbar) to compare with the source, and cycle the theme to see that diagrams follow it.

| Page | Shows |
|---|---|
| [text.md](text.md) | headings, lists, tables, task lists, footnotes, sub/superscript, links |
| [code.md](code.md) | highlighting, line numbers, highlighted lines, the Copy button |
| [callouts.md](callouts.md) | the five GitHub callouts and collapsible sections |
| [math.md](math.md) | inline and display equations |
| [mermaid.md](mermaid.md) | flowchart, sequence, state, class, ER, Gantt, pie, git graph |
| [mindmap.md](mindmap.md) | mind maps (Mermaid's `mindmap`, plus a timeline) |
| [graphviz.md](graphviz.md) | DOT graphs |
| [drawio.md](drawio.md) | draw.io diagrams, plain or compressed |
| [canvas.md](canvas.md) | JSON Canvas (Obsidian) with text, file and link nodes, groups and edges |
| [infographic.md](infographic.md) | AntV infographics from a few lines of text |
| [vega.md](vega.md) | Vega-Lite and Vega charts, drawn from data written in the page |
| [images.md](images.md) | the image viewer (click a picture), a linked image that is left alone, a missing file |
| [layout.md](layout.md) | page width, text size, line spacing and font, with the contents panel following the width |
| [keyboard.md](keyboard.md) | every keyboard shortcut, and the Files tree's arrow keys |
| [frontmatter.md](frontmatter.md) | the title block and status badge |

Diagrams draw when they scroll into view, so a long page costs nothing until you reach them.
