# Mind maps

A mind map is a Mermaid diagram, so it follows the theme like the rest.

```mermaid
mindmap
  root((mt-md))
    Reading
      Themes
      Contents panel
      Files panel
    Drawing
      Mermaid
      Graphviz
      Vega
    Output
      Print
      Bundle for an LLM
```
